## Reading these numbers

* No interpolation cell used on this report grid touches the adf15 1e-74 zero sentinel, so every number above is an interpolation between real tabulated values.
* The He+ Te = 1 eV row is still not quotable. Every He II line needs ~40 eV to excite, so that row sits in a grid cell spanning ~11 decades of PEC (0.689 -> 1.03 eV), where a log-linear interpolant stands in for a steep Arrhenius exponential -- order of magnitude at best. It is also irrelevant: at 1 eV the He+ line power is ~8 decades below the He0 line power at the same point. Quote the Te >= 5 eV rows.
* Interpolation is clamped at each file's own grid edges, so a (ne, Te) outside a file's coverage returns its nearest edge value rather than an extrapolation. Both adf15 grids cover the whole report grid, so no clamping engages here.
* The band edges are window-transmission boundaries, not spectroscopic ones: <170 nm has no window at all, 170-300 nm needs fused silica, 300-350 nm is marginal through borosilicate, >350 nm passes ordinary glass.
